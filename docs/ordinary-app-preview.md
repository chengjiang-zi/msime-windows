# 普通应用预览实验

此实验分支仅在一次性 GitHub Windows 测试机上验证：关闭服务进程的 `uiAccess` 后，是否能在不把自签名开发证书加入系统信任库的情况下，在普通权限应用中运行输入法。

这会降低权限相关能力：候选窗口可能无法覆盖管理员权限应用，也不能宣称支持 UAC 安全桌面。该实验不代表正式签名、真实 UAC 安装或所有软件兼容性已经解决；不可直接作为正式版本发布或安装到日常电脑。原有个人版分支的 `uiAccess` 配置不变。

构建完成后，检查不导入证书的诊断结果是否明确报告 `ordinary-input-worked`，同时确认确实执行了真实输入测试而非跳过。如果失败或环境不可用，必须记录实际结果，不得当成通过。
