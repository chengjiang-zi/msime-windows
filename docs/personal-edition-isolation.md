# 个人版并存改造：开发记录

目标是在同一台 Windows 上安装个人版和水杉原版，两者可分别启用、配置、更新和卸载。
在下列检查全部通过之前，安装器必须保持禁止构建；仅修改安装目录不能保证并存。

## 当前进度

- 已将共享的 Windows IPC 管道、事件和共享内存名称换到个人版命名空间；TSF 与 Server 仍使用同一份契约。
- 已添加对应契约检查，并在本地运行 x64 和 x86 契约测试。
- 已为 TSF 使用的 16 个私有 GUID 分配个人版身份，并同步看门狗、设置程序和卸载路径中的 profile 标识；静态一致性检查已通过。
- 已改用个人版的注册表项、后台进程名、单实例锁、窗口类和数据目录；数据路径环境变量使用 `CHENGJIANG_IME_DATA_DIR` 和 `CHENGJIANG_IME_CONFIG_DIR`。
- 安装器的路径重叠策略会拒绝原版数据、程序及 TSF 目录及其父子目录，并拒绝含重解析点的路径；本地 Inno Setup 探针覆盖了普通路径、`..` 和 junction。
- 上游自动更新在个人版中停用，避免把原版安装包误作为个人版更新；个人版开发证书使用独立 subject。
- 安装器默认禁止打包；仅一次性 GitHub 托管 Windows 运行器可构建测试包，并在上传前运行原版与个人版的并存、路径拒绝和卸载检查。
- 开发包使用一次性自签名证书；即使 CI 通过，也不能据此认定真实桌面和所有输入法宿主均已验证。

## 必须完成的隔离

1. 在构建及 Windows 虚拟机中验证新的 TSF 身份、设置程序、看门狗与卸载路径是否一致。
2. 复核 Server、启动锁、看门狗、配置锁及其他命名对象；在实际并存测试中验证进程退出、计划任务和窗口消息只操作个人版。
3. 验证安装程序 AppId、系统 DLL 目录、程序目录、注册表键、用户数据和设置路径已完整隔离；个人版卸载不得触碰原版文件或注册信息。
4. 隔离默认输入法设置、更新地址、版本识别及开始菜单入口；显示名称需清楚说明基于水杉输入法。
5. 审计轻量包、升级、数据迁移、词库生成、卸载和异常回滚；保留 GPL 和第三方授权声明。
6. 完整构建 x64/x86 TSF 和 Server，运行 IPC、安装器及服务端测试。
7. 在一次性 Windows 虚拟机中先装原版，再装个人版；验证切换、同时运行、独立配置、升级和分别卸载，确认原版词库及设置未变化。

完成上述检查后才能移除安装器保护，并在用户电脑上安排试用。
