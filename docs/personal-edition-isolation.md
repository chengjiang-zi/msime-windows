# 个人版并存改造：开发记录

目标是在同一台 Windows 上安装个人版和水杉原版，两者可分别启用、配置、更新和卸载。
在下列检查全部通过之前，安装器必须保持禁止构建；仅修改安装目录不能保证并存。

## 当前进度

- 已将共享的 Windows IPC 管道、事件和共享内存名称换到个人版命名空间；TSF 与 Server 仍使用同一份契约。
- 已添加对应契约检查，并在本地运行 x64 和 x86 契约测试。
- 已为 TSF 使用的 16 个私有 GUID 分配个人版身份，并同步看门狗、设置程序和卸载路径中的 profile 标识；静态一致性检查已通过。
- 已改用个人版的注册表项、后台进程名、单实例锁、窗口类和数据目录；数据路径环境变量使用 `CHENGJIANG_IME_DATA_DIR` 和 `CHENGJIANG_IME_CONFIG_DIR`。
- 安装器的路径重叠策略会拒绝原版数据、程序及 TSF 目录及其父子目录，并拒绝含重解析点的路径、短文件名、网络路径和虚拟盘符；比较时会解析本地卷的设备名称。本地 Inno Setup 探针覆盖了普通路径、`..`、junction、短文件名和网络路径，虚拟盘符测试只在一次性 GitHub 运行器上执行。为降低误删风险，暂不支持把数据目录设置到网络、SUBST 盘或路径包含 `~` 的位置。
- 上游自动更新在个人版中停用，避免把原版安装包误作为个人版更新；个人版开发证书使用独立 subject。
- 安装器默认禁止打包；仅一次性 GitHub 托管 Windows 运行器可构建测试包，并在上传前运行原版与个人版的并存、路径拒绝和卸载检查。
- 开发包使用一次性自签名证书；即使 CI 通过，也不能据此认定真实桌面和所有输入法宿主均已验证。
- 每次云端开发构建都生成新的证书，默认有效期 90 天，私钥随运行器销毁；它不是适合长期安装和升级的签名方案。正式发布前需要单独解决可信签名与证书更新问题，不能让用户为每次构建反复信任新证书。
- [免导入证书诊断](https://github.com/chengjiang-zi/msime-windows/actions/runs/40749881046)中，安装包能够安装，但 Windows 拒绝启动带 UIAccess 的 Server，普通输入测试无法完成；该诊断没有向信任存储导入个人版证书。结果只适用于这组测试环境，不能把免信任证书当作目前可用的试用方式。
- 对原版 v0.12.0 的一次性机器实测发现：静默安装的向导页会覆盖 `/DATADIR` 指定值，仍使用默认数据路径。个人版已调整静默路径选择，并存测试以原版注册表记录的实际路径为准；此修正仍需完整安装测试。
- [一次性 Windows 自动测试](https://github.com/chengjiang-zi/msime-windows/actions/runs/40715098297)已验证两版同时运行、个人版 IPC、数据目录重叠拒绝、个人版升级保留自定义词条，以及先卸载任一版本后另一版仍保留数据和注册。个人版卸载后当前用户的键盘列表条目也已清除。
- [真实输入框与候选框自动测试](https://github.com/chengjiang-zi/msime-windows/actions/runs/40723101367)已验证个人版上屏中文，以及一组开启译文、固定位置的退格场景；其他宿主、多显示器、不同缩放和人工视觉体验仍未验证。
- [账户处理接入后的回归](https://github.com/chengjiang-zi/msime-windows/actions/runs/40731688079)已验证桌面用户识别与失败时保守退出的独立探针、为标准账户创建无密码交互式任务的独立探针，以及同账户的完整安装、升级、卸载和输入。
- 安装和卸载时，个人版通过绑定桌面用户的临时任务登记或清理该用户的键盘条目。[不同管理员身份下的安装和卸载测试](https://github.com/chengjiang-zi/msime-windows/actions/runs/40740483770)已验证数据目录、键盘条目和后台进程属于桌面用户，清理任务不可用时卸载停止且官方版未受影响；该测试没有操作真实的 UAC 凭据对话框。
- 安装完成页改为启动绑定桌面用户的看门狗任务；安装后步骤失败时不自动启动，并为静默调用返回非零状态。[独立探针](https://github.com/chengjiang-zi/msime-windows/actions/runs/40744637109)已验证安装后异常返回失败码；[完整安装回归](https://github.com/chengjiang-zi/msime-windows/actions/runs/40742833035)已通过。
- 新安装的数据目录改为向桌面用户 SID 授予修改权限，不再主动向整个本机 Users 组授权；不会撤销目录原本继承的权限。[独立诊断](https://github.com/chengjiang-zi/msime-windows/actions/runs/40742832969)已验证普通账户可以修改由管理员创建的数据文件，并已通过完整安装回归。
- [服务端回归](https://github.com/chengjiang-zi/msime-windows/actions/runs/40742833035)首次运行时主测试套件在 120 秒超时，重跑后约 51 秒通过；首次超时的具体原因尚未定位。

## 必须完成的隔离

1. 在构建及 Windows 虚拟机中验证新的 TSF 身份、设置程序、看门狗与卸载路径是否一致。
2. 复核 Server、启动锁、看门狗、配置锁及其他命名对象；在实际并存测试中验证进程退出、计划任务和窗口消息只操作个人版。
3. 验证安装程序 AppId、系统 DLL 目录、程序目录、注册表键、用户数据和设置路径已完整隔离；个人版卸载不得触碰原版文件或注册信息。
4. 隔离默认输入法设置、更新地址、版本识别及开始菜单入口；显示名称需清楚说明基于水杉输入法。
5. 审计轻量包、升级、数据迁移、词库生成、卸载和异常回滚；保留 GPL 和第三方授权声明。
6. 完整构建 x64/x86 TSF 和 Server，运行 IPC、安装器及服务端测试。
7. 在一次性 Windows 虚拟机中先装原版，再装个人版；验证切换、同时运行、独立配置、升级和分别卸载，确认原版词库及设置未变化。

完成上述检查后才能移除安装器保护，并在用户电脑上安排试用。
