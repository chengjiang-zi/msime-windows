# 个人版功能计划

先确保个人版能够与水杉原版独立安装、使用和卸载，再逐项完善日常输入体验。下表是计划，不代表功能已经可用。

| 方向 | 当前状态 | 下一步 |
| --- | --- | --- |
| 独立安装和并存 | 一次性 Windows 环境已验证同账户和不同管理员身份下的安装、卸载及新权限；[普通应用预览](https://github.com/chengjiang-zi/msime-windows/actions/runs/40773823076)在无证书信任、模拟受限令牌时成功输入 | 明确高权限窗口限制，继续验证真实标准账户和 UAC 凭据流程；正式签名仍待解决 |
| 翻译候选窗口稳定 | 已在个人分支实现尺寸稳定策略，并在一个真实输入框场景中自动验证 | 在不同布局、屏幕缩放和宿主程序中试用；当前策略允许窗口在内容变长时扩展 |
| 固定候选窗口位置 | 上游已有“候选窗口跟随光标”设置；关闭后仅在当前候选窗口显示期间保持首次位置 | 实际试用后，再决定是否增加跨输入会话固定在屏幕某处的功能 |
| 左右方向键和候选数量 | 上游已有横排左右键移动候选项的选项，也可设置每页候选数量；[自动测试](https://github.com/chengjiang-zi/msime-windows/actions/runs/40752026770)验证了每页三、六、九个时右键进入下一页 | 在更多宿主和实际使用中验证，再根据反馈改进 |
| 英文整句翻译成中文 | 计划中 | 设计明确的触发方式和确认上屏步骤；在线翻译需告知用户会发送的文本 |
| 闲暇时看单词 | 计划中 | 先做可关闭、不打断输入的轻量展示，再考虑收藏和复习；不直接使用百词斩的受版权保护内容 |
| 输入时优先显示释义 | 上游已有候选词释义和自定义翻译 | 试用现有词库和排序方式，按使用体验决定是否调整 |
| 扩展词库 | 上游支持英文词库管理、导入和导出 | 先明确来源、授权和导入格式，再按需求补充 |
| AI 一键写答案 | 计划中 | 支持手动触发与快捷键，先设计上下文来源、确认和服务配置，避免未经用户操作发送文本 |
| 点击输入中的文字移动光标 | [隔离诊断](https://github.com/chengjiang-zi/msime-windows/actions/runs/40767716041)发现候选框透明区域会挡住点击；临时调整区域后，富文本控件的鼠标捕获仍影响选词 | 继续研究宿主交互和后台光标同步；实验功能尚未合入，仍需覆盖更多宿主 |

候选窗口测试范围与人工试用步骤见[候选框测试说明](candidate-window-manual-test.md)。

上游已有的设置入口：在「外观」中选择横排和「每页候选项数量」（3～9），在「快捷键」中勾选「左 / 右（横排时移动候选项）」。关闭「候选窗口跟随光标」可让窗口在当前一次输入期间保持首次位置。
